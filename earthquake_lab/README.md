# Earthquake Forecast Research Pipeline

日本域の短期地震発生確率を、公開カタログだけで再現可能に学習・評価する隔離研究パイプラインです。

主系統は ETAS/Hawkes 型の時間空間スケーリング則を基準にし、因果的な活動度・背景率・静的応力包絡プロキシを軽量残差モデルで補正します。研究比較には XGBoost を追加しますが、スマホ配布用 `browser_hybrid` は ETAS + 標準化ロジスティック残差モデルだけで構成し、係数を `model_bundle.json` に書き出します。

入力は USGS FDSN/ComCat と、気象庁「地震月報（カタログ編）」年別震源データを選択できます。JMA レコードは公式固定長フォーマットを読み、自然地震かつ K/k/A 品質の震源を使用します。

評価はランダム分割を使いません。最終365日を完全なテスト期間、その直前365日をスタッキングと確率校正に確保し、それ以前のみで基礎モデルを学習します。ROC-AUC、PR-AUC、Brier Skill、Log Loss、climatology に対する情報利得、上位10%領域での捕捉率、ECEを出力します。

`model_bundle.json` は静的Webアプリから読み込める軽量な配布形式です。応力特徴は発震機構を入力していないため符号付きCoulomb応力ではなく、静的応力包絡の補助特徴です。
