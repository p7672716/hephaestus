Hephaestus UI Design System & Coding Instructions

このドキュメントは、ローカルAIツール「Hephaestus」の持つ、温かみのあるエディトリアル（編集）スタイルを完璧に再現するための、AIコード生成モデル（Codex/Claude等）向けのデザイン指示書です。

新しいコンポーネントや追加画面をコーディングする際は、以下のルールを厳格に遵守してください。

1. デザイン思想（Philosophy）

脱・サイバーパンク / 脱・ネオン: ありがちな黒背景にネオンブルー、SF風グリッド、点滅するサイバーインジケーターを完全に排除します。

工芸とエディトリアル: 上質な学術書、建築設計事務所のポートフォリオ、あるいは手になじむアナログ工具のような「温かみ」「静寂」「クラフトマンシップ」を追求します。

触覚的な静寂: 無駄な動きをさせず、状態の切り替えやホバー時は、物理的な紙をめくったりダイヤルを回すかのような、なめらかで控えめなイージング（摩擦を感じる動き）を適用します。

2. デザイン・トークン（Tailwind & CSS Tokens）

コード内で使用する色、余白、境界線、フォントファミリーは、以下の定義に完全に統一してください。

A. タイポグラフィ（Typography）

ブランド / イタリック / 見出し: Cormorant Garamond (Serif体)

用途: ロゴ、特徴的な見出し、斜体（italic）表現、AIモデル名

プライマリUI / 本文 / ラベル: Plus Jakarta Sans (Humanistゴシック体)

用途: ボタン、設定項目、数値表示、通常のシステム文

コード / ステータス数値: Space Mono などの等幅フォント（Monospace）

B. カラーパレット（Color Palette）

純粋な黒（#000000）や純粋な白（#FFFFFF）は使用せず、インクと温かい紙を再現したローコントラストな色調を使用します。

Light Mode (Solar Canvas)

全体背景: #FAF8F5 (温かみのあるオフホワイト)

サイドバー背景: #F2EDE2 (やや深みのあるサンドベージュ)

カード/パネル背景: #FCFAF7 (純白に近い薄ベージュ)

テキスト（主）: #242426 (漆墨 - わずかに温かみのある黒)

ボーダー/境界線: #ECE7DC (極薄の土壁色)

アクセント（プライマリ）: #C55734 (テラコッタ・レンガ色)

アクセント背景/ライト: bg-[#C55734]/10 text-[#C55734] border-[#C55734]/20

Dark Mode (Studio Void)

全体背景: #121213 (限りなく黒に近い消炭色)

サイドバー背景: #161618 (やや深みのある黒)

カード/パネル背景: #18181A (中間のチャコール)

テキスト（主）: #E4DEC9 (暖かみのある羊皮紙色)

ボーダー/境界線: #262629 (極薄のダークグレー)

アクセント（プライマリ）: #D06C4C (温かみのある錆オレンジ)

アクセント背景/ライト: bg-[#D06C4C]/10 text-[#D06C4C] border-[#D06C4C]/25

3. インタラクション＆モーションルール

AIが勝手にチカチカしたアニメーションを作らないよう、以下のキーフレームを常にCSSとして注入させます。

A. ページ遷移（マイクロインタラクション）

タブ切り替えや表示のフェードインには、以下の「せり上がりフェード」のみを許可します。

@keyframes pageSlide {
  0% {
    opacity: 0;
    transform: translateY(12px);
  }
  100% {
    opacity: 1;
    transform: translateY(0);
  }
}
.animate-page-slide {
  animation: pageSlide 0.6s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}


B. ステータスインジケーター（呼吸するドット）

稼働中のインジケーターは、高速に点滅（blink）させず、4秒以上の非常に長い周期で「ゆっくり呼吸する」ように明滅させます。

@keyframes organicPulse {
  0%, 100% {
    opacity: 0.65;
    transform: scale(1);
  }
  50% {
    opacity: 1;
    transform: scale(1.15);
  }
}
.organic-pulse {
  animation: organicPulse 4s ease-in-out infinite;
}


4. UIコンポーネントの実装ルール

サイドバー: w-64（展開時）からw-20（折りたたみ時）へ、イージング transition-all duration-300 ease-out を用いて、テキストを隠しながらなめらかに幅が縮小するように実装します。折りたたみ時はホバー時に absolute の極小ツールチップを表示します。

インプット＆テキストエリア:

ボーダーは極細（border 1px）。

フォーカス時に突然太い青枠を出すのは禁止。フォーカス時は border-color: {アクセント色} に変化させ、box-shadow を1pxの極薄でぼかしてじんわりと光らせます。

スライダー (Range Input):

太い標準バーは使用せず、トラック高 3px の極細線を使用します。

つまみ（Thumb）は 11px 四方の小さな円形（アクセント色）にし、ホバー時に scale(1.25) に滑らかに拡大させます。

プログレスバー / ローディング:

常に transition-all duration-1000 ease-out などのイージングを効かせ、1コマずつピクセルがカクカク動くのを防ぎます。

5. アンチパターン（絶対にやってはいけないこと）

絶対にしないこと:

グラデーションを多用した派手なボタン（例: bg-gradient-to-r from-purple-500 to-pink-500 など）

角丸の過剰な適用（カードやボタンは rounded 程度に抑え、丸みを持たせすぎない。rounded-full はアイコンボタンまたはトグルのみ）

青色（text-blue-500 や #007bff）をシステム通知以外のプライマリカラーに使用すること

白や黒をベースにした極端なフラットデザイン

6. Codexへの指示用テンプレートプロンプト

このシステム仕様に従って新しいUI要素を作成する際は、指示の先頭に以下のシステムプロンプトを付与してください：

あなたは「Hephaestus UIデザインシステム」に完全準拠する熟練のフロントエンドエンジニアです。
インポートされたフォント「Cormorant Garamond（セリフ体）」と「Plus Jakarta Sans（サンセリフ体）」を完璧に使い分け、温かみのあるエディトリアルなLight/DarkテーマのUIコードを生成してください。
サイバーパンクやネオン、純白・純黒は厳禁です。静寂、クラフトマンシップ、なめらかなマイクロトランジションを意識してコーディングしてください。
